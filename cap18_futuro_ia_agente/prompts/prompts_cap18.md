## Prompt 3: Diseñar un Agente de Análisis de Datos
```
Necesito un agente de IA que analice datasets automáticamente.

Diseña un agente que:
1. Reciba la ruta a un CSV
2. Explore la estructura del dataset
3. Identifique problemas de calidad
4. Genere estadísticas descriptivas
5. Detecte outliers
6. Proponga visualizaciones
7. Retorne un reporte ejecutivo

Incluye:
- Arquitectura del agente (componentes)
- Herramientas necesarias (tools)
- Prompt del agente
- Ejemplo de ejecución paso a paso
- Consideraciones éticas (¿puede tomar decisiones?)

Formato: Código + diagrama + explicación
```

## Prompt 4: Implementar Supervisión Humana en Agentes
```
Necesito implementar un sistema de supervisión humana para un agente de aprobación de créditos.

El agente debe:
1. Evaluar solicitudes automáticamente
2. Clasificar en: aprobado/rechazado/revisión humana
3. Explicar cada decisión
4. Registrar todo en log de auditoría
5. Escalar a humano cuando el riesgo sea ambiguo

Define:
- Umbrales de decisión (¿cuándo escalar?)
- Métricas de evaluación del agente
- Protocolo de revisión humana
- Dashboard de monitoreo
- Alertas automáticas

Formato: Diagrama de flujo + código + métricas
```

## Prompt 5: Evaluar Riesgos Éticos de IA Autónoma

1. Identificación de sesgos potenciales en el modelo

3. Transparencia y explicabilidad

5. Responsabilidad legal y regulatoria
6. Plan de mitigación para cada riesgo

## Prompt 6: Crear un Pipeline Completo con Agentes
```
Necesito un pipeline completo de ciencia de datos orquestado por agentes.

El pipeline debe tener 4 agentes:
1. Agente de Ingesta: Carga y valida datos
2. Agente de Limpieza: Maneja nulos, duplicados, formatos
3. Agente de Análisis: Estadísticas, correlaciones, outliers
4. Agente de Reporte: Genera executive summary

Para cada agente, define:
- Rol y objetivo
- Herramientas disponibles
- Input/output esperado
- Criterios de éxito
- Mecanismo de escalamiento

Incluye:
- Código completo (LangChain o CrewAI)
- Diagrama de flujo
- Ejemplo de ejecución
- Métricas de calidad del pipeline
```

## Prompt 7: Reflexión Ética sobre Autonomía de IA
```
Escribe un ensayo de 500 palabras sobre los riesgos éticos de la IA autónoma en ciencia de datos.

Estructura:
1. Introducción: El dilema de la autonomía
2. Riesgos técnicos: Sesgos, errores, falta de explicabilidad
3. Riesgos sociales: Desempleo, desigualdad, dependencia
4. Riesgos existenciales: Referencia a Butlin (2023)
5. Soluciones: Supervisión humana, auditoría, regulación
6. Conclusión: El futuro es híbrido (humanos + IA)

Incluye:
- Al menos 3 referencias académicas
- Ejemplos concretos de cada riesgo
- Propuestas accionables
- Reflexión personal sobre el rol del científico de datos
```
